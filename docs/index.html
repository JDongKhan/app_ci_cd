ShipFlow · Internal Delivery

代码合并与打包平台

把需求、任务、CI 流水、代码合并、打包和产物串成一条可追踪的交付链路。 一期以本地可运行为先，使用 SQLite 文件数据库，真实执行 Git 合并与构建脚本， 同时保留迁移到 PostgreSQL 的仓储抽象。
